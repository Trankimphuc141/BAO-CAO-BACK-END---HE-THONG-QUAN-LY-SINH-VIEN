# Cổng Thông Tin Sinh Viên - Frontend (React + Vite)

## Cấu trúc thư mục:
- `src/components/`: Chứa các Component tái sử dụng (Sidebar, Header, AuthModal, SurveyModal...).
- `src/pages/`: Chứa các màn hình chính (Dashboard, ProfilePage, TimetablePage, AttendancePage, ExamPage, SurveyPage, ThesisPage).
- `src/services/`: Tầng giao tiếp API gọi Back-end (`api.js`).
- `src/assets/`: Hình ảnh, tài nguyên tĩnh.
- `App.jsx`, `main.jsx`: Điểm khởi chạy React Application.
